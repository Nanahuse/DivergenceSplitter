公開設定は[Profileリファレンス](../configuration.md)と[YAMLリファレンス](../scenarios/yaml-reference.md)にまとめています。ローダーや評価動作を変えた場合は文書も更新してください。画面名から仕様を推測せず、現在の実装とテストで確認します。

利用者向けドキュメントだけを日英の2言語で用意します。対象はルートREADME、導入・利用ガイド、設定、Scenario・Condition・Detector、サンプル、トラブルシューティング、NDIランタイムの利用者向け説明です。日本語版を正本、英語版を翻訳とし、差がある場合は日本語版を優先します。

開発・設計・ビルド・テスト・CI・配布手順、移行受け入れ記録、テストデータの説明は日本語のみです。ライセンス原文や正式な法的通知はこの翻訳方針の対象にせず、必要な原文を維持します。

利用者向け文書を変更するときは、日本語版の修正を対応する英語版にも反映してください。設定キー・数値・コード例をそろえ、両言語のリンクを確認します。Scenarioリファレンスは設定と動作、シナリオ例は実現できる条件、利用ガイドはGUIでの操作を説明します。内部設計や実装上の判断は開発者向け文書にまとめ、同じ説明を繰り返さないようにします。

文書や例を変えた場合は、完全なYAMLを `load_scenario` またはProfile経由のCLI `--check` で検証し、JSONを `load_profile` で確認してください。相対リンクと見出しアンカーも解決できることを確認し、対象ブランチの実装と比較します。`--check` は入力とROIの実際の互換性を検査しないため、その確認にはフレームを使うテストが必要です。[例の検証](testing.md#ドキュメントの例の検証)を参照してください。
