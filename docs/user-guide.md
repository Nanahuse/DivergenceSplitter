## Monitor

Monitorでは、入力映像、接続状態、判定結果を確認できます。入力の状態と取得したフレーム数を見るには、Captureにポインターを置きます。Crop／Resize後の映像を見るには、Previewを押して別ウィンドウを開いてください。

### インスタンスの状態確認

Instanceと書かれたカードに、接続状態と判定のFPSが表示されます。このFPSは、そのインスタンスが1秒あたりに判定したフレーム数です。

Readyは、LiveSplit.Bridgeに接続してタイマー情報の同期が済んだ状態です。映像の受信とシナリオの判定は、Captureと各インスタンスのグラフで確認してください。接続が切れたインスタンスはタイマー操作の判定を止めます。他のインスタンスはそれぞれの接続状態に従って動作します。

タイマーの状態、Split位置、接続先、最後の操作結果は、カードのDetailsを押すと確認できます。Instance番号は0から、画面上のRuleとSplit番号は1から始まります。

PendingやWaiting for Reset confirmationが表示された場合は、[操作の確定待ちとResetの失敗](troubleshooting.md#操作の確定待ちとresetの失敗)を参照してください。

### 判定結果とグラフ

カードには、通常の判定を表示するStart / Splitと、シナリオのReset判定を表示するResetのグラフがあります。どちらも直近30秒を表示します。Ruleや `then` のステップが変わっても、表示期間内の系列は残ります。現在判定している系列は濃い色で表示されます。

- 数値の系列は、目標を100%として0〜125%の範囲で表示します。目標が0以下の条件や真偽値の条件では、成立を点、不成立を横線で示します。
- Condition名の前のアイコンは、チェックが成立、丸が不成立、四角が未評価、横線が評価の省略、バツがエラーです。
- グラフの空白は未測定の区間です。オレンジ色の太い縦線はタイマーのResetを示します。

### グラフの詳細表示と操作

Condition名やグラフの系列を選ぶか、Detailsを押すとHistory detailsが開きます。Ruleの選択欄では、以前のSplitやRuleSequenceの各Ruleを選べます。左側のツリーでは、組み合わせた子Conditionや `then` の各ステップを選べます。Splitが進んでも詳細画面は開いたままです。

選んだConditionに応じて、`detected` のスコアとしきい値、`elapsed` と `hold` の経過時間と目標、`nth` の回数、`then` の進行などを表示します。評価が省略されたときはLast valueに前回の値が表示されます。状態の遷移は緑、エラーは赤で表示されます。

詳細グラフのライブ表示は直近60秒です。ホイールで拡大・縮小、ドラッグで移動、右ドラッグで範囲選択ができます。操作すると表示時刻が固定され、同じ時間軸で値と状態を確認できます。Resume liveまたはReset viewを押すとライブ表示に戻ります。再接続やProfileの再適用後は、新しい履歴を表示します。

### Detectorの比較

詳細画面のCompare detectorsで、同じインスタンスのDetectorを複数選び、スコアを同じ時間軸で比較できます。検出したい場面と誤検出しやすい場面の両方を確認し、方式やしきい値を調整してください。Conditionsを押すとConditionの詳細に戻ります。

### Reset All

Reset Allを2秒間押し続けると、各インスタンスにタイマーのResetを要求します。2秒経つ前にボタンを離すか、ポインターをボタンの外へ動かすとキャンセルできます。

Resetを送る対象は、操作できるインスタンスのうち、タイマーがRunning、Paused、Endedのものです。操作結果はインスタンスごとに確認してください。Reset後に開始条件が成立すると、Runが再び始まる場合があります。

## Profileの操作

Profileでは、映像入力と画像変換、各インスタンスのBridgeポートとシナリオのファイルパスを設定します。入力と画像変換は、すべてのインスタンスで共通です。

Scenarios & Connectionsで、Add instanceを押して行を追加します。各行のBrowseでシナリオを指定し、不要な行はRemoveで削除します。別々のLiveSplitを操作する場合は、行ごとに異なるBridge portを指定してください。[複数インスタンスの設定](configuration.md#複数インスタンス)を参照してください。

| 操作 | 動作 |
| --- | --- |
| 項目を編集 | 編集中の下書きだけが変わります。実行中のシナリオには、まだ反映されません。 |
| Apply | シナリオと参照画像を読み込み、選んだ入力を検証して、下書きの設定で実行を始め直します。映像取得と各インスタンスの状態をリセットし、動画は先頭に戻します。Profileのファイルには保存しません。 |
| Revert draft | 下書きを、現在適用している設定に戻します。 |
| Open | JSONを読み込んですぐに適用し、下書きも置き換えます。 |
| Save | 現在の下書きを既存のファイルに保存します。保存先が未指定なら選択画面が開きます。 |
| Save As | 保存先を選び、現在の下書きをJSONに保存します。 |

設定を変更したら、下書きプレビューで映像を確認してからApplyを押します。Monitorで動作を確かめたあと、SaveまたはSave Asで下書きを保存してください。保存の前にApplyすると、実行に必要なシナリオや入力設定を検証できます。

映像入力を開く処理はApplyの後も続くため、Applyが成功してから入力エラーが表示される場合があります。Monitorで結果を確認し、必要な修正をしてから、もう一度Applyしてください。

YAMLや参照画像を編集して保存しても、自動では読み直しません。変更を反映するにはProfileを再びApplyするか、開き直してください。

Profileを開くか保存すると、アプリはそのパスを記憶します。次回起動時にそのファイルが残っていれば、自動で読み込んで適用を試みます。映像とBridgeの準備が整うと、保存済みのシナリオがタイマーを操作する場合があります。

### 入力の下書きプレビュー

Applyの前に映像を確認するには、InputにあるInput PreviewのPreview inputをオンにします。シナリオを実行中の場合は、Stop Session and preview draftで実行を止めてから確認します。Applyを押すと、下書きの設定で実行を再開します。

表示するのは、開いた入力の寸法、入力側が報告するFPS（取得できる場合）、実際に受信したFPS、変換後の寸法です。Crop／Resizeだけを変えた場合は、入力を開き直さずに表示を更新します。送信元が一時停止していても、最後に受信した画像で変換結果を確認できます。

プレビューで確認できるのは、入力映像とCrop／Resizeの結果です。シナリオの判定やBridge操作、Resize reference imagesで変換した参照画像は、Apply後にMonitorで確認してください。

Profileから別の画面へ移ったとき、Preview inputをオフにしたとき、またはシナリオの実行を始めたときに、プレビューの入力を閉じます。動画はプレビュー中も再生されますが、Applyすると先頭に戻ります。プレビューでエラーが出たら入力を修正するか、Preview inputを切り替えて再試行してください。

## Settings

| 項目 | 設定内容 |
| --- | --- |
| Log level | 記録するログのレベルを `OFF`、`DEBUG`、`INFO`、`WARNING`、`ERROR` から選びます。既定値は `INFO` です。 |
| Reaction time (ms) | 映像を取得してから自動操作を送るまでの待ち時間です。判定にかかる時間を含みます。画面では0〜5000ミリ秒を指定でき、既定値は `0` です。[操作を送るタイミング](scenarios/yaml-reference.md#操作を送るタイミング)を参照してください。 |
| Theme | LightまたはDarkを選びます。Applyを押すと画面の配色が変わります。 |

SettingsのApplyで変更を保存します。Reloadは、保存済みの値を画面に戻します。Reaction time (ms)とLog levelの変更を実行中のシナリオに反映するには、Profileを再びApplyしてください。保存先とJSONの形式は[アプリケーション設定](configuration.md#アプリケーション設定)を参照してください。

## About

Aboutでは、アプリのバージョン、プロジェクトへのリンク、第三者コンポーネントのライセンスと通知を確認できます。ライセンス全文と通知は配布ZIPの `licenses/` と `DISTRIBUTION-NOTICE.txt` にあります。外部コンポーネントのNDI Runtimeが検出されたかは、ProfileのNDI入力設定で確認してください。
